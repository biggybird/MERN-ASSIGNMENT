# MERN Assignments

A collection of my first-semester web development assignments, built while learning HTML and CSS.

## Assignments

| Folder | Project | Concepts Practised |
| --- | --- | --- |
| [Assignment1](./Assignment1/) | Personal Portfolio | HTML structure, navigation, lists, images and basic CSS |
| [Assignment2](./Assignment2/) | Job Application Form | Form elements, input types, labels, validation and responsive CSS Grid |
| [Assignment3](./Assignment3/) | Library Inventory | HTML tables, captions, table sections, merged cells and styling |
| [Assignment4](./Assignment4/) | Personal Portfolio | Improved portfolio layout, reusable styling and responsive design |
| [Assignment5](./Assignment5/) | Leaf & Bean Cafe Landing Page | Positioning, overlays, layout, cards and gallery |

## Tech Stack

- HTML5
- CSS3

## Run Locally

1. Clone this repository:
   `git clone https://github.com/biggybird/MERN-ASSIGNMENT.git`
2. Open the project folder.
3. Open an assignment's `index.html` file in your browser.

No build tools or installation required.
