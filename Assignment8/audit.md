# Assignment 09 - Responsive Audit

## Project
Leaf & Bean Cafe

## Breakpoints Used

1. Desktop: Above 768px
2. Tablet: 768px
3. Mobile: 480px

## Problems Identified and Fixed

| Problem | Solution |
|---|---|
| Navigation links overflow | Used flex-wrap |
| Cards become too narrow | Added minimum width |
| Cards overflow on mobile | Changed flex-direction to column |
| Images overflow | Used width: 100% and overflow: hidden |
| Buttons too close | Added padding |
| Footer alignment issues | Used flex-direction: column on mobile |

## Testing

Tested viewport sizes:

- Desktop: 1200px
- Tablet: 768px
- Mobile: 375px

## Conclusion

The website uses CSS Flexbox and media queries
to provide a responsive layout across different
screen sizes.
